# 문장 배경화면

쓰고 싶은 문장을 적으면 iPhone 잠금화면 배경화면으로 만들어 줍니다.
배경색, 글자색, 글꼴만 고르면 배치는 알아서 맞춰집니다.

## 쓰는 법

1. iPhone Safari로 페이지를 엽니다.
2. 문장을 쓰고 색과 글꼴을 고릅니다. 미리보기에 시계와 버튼 자리가 겹쳐 보입니다.
3. **배경화면으로 설정**을 누르고, 공유 시트에서 **문장 배경화면** 단축어를 고릅니다.

단축어 없이 쓰려면 **이미지로 저장**을 누른 뒤 사진 앱에서 직접 배경화면으로 지정하면 됩니다.

## 단축어 설치

- 파일로 설치: [`shortcut/문장 배경화면.shortcut`](shortcut/) 을 iPhone에서 열고 **단축어 추가**.
- 직접 만들기: [`shortcut/BUILD.md`](shortcut/BUILD.md) 참고. 동작 하나(배경화면 사진 설정 → 잠금 화면, 미리보기 끔)면 됩니다.

잘 안 될 때:
- **"선택한 배경화면에 사진을 설정할 수 없습니다"**: 지금 잠금화면이 사진 배경화면이 아니라서 그렇습니다. 잠금화면을 길게 눌러 **+ → 사진**으로 아무 사진 배경화면을 하나 만든 뒤 다시 실행하세요.
- 시계를 길게 늘려 쓰면(iOS 26 이상) 문장과 겹칠 수 있습니다. 기본 시계 크기를 권장합니다.

## 개발

빌드 없음. 정적 파일 그대로 서빙합니다.

```sh
python3 -m http.server 8000   # http://localhost:8000
node render.test.mjs          # 레이아웃 계산 테스트
```

- `index.html`: 화면, 미리보기, 공유
- `render.js`: 줄바꿈, 글자 크기 맞춤, 캔버스 그리기
